# brumbrumki.com - Commercial Car Rental Platform 🚗

A production-ready website developed for a real-world car rental business located near Warsaw. Originally developed in 2022/2023, the project has been actively maintained, refactored, and updated throughout 2024 and 2025.

🔗 **Live Project:** [brumbrumki.com](https://brumbrumki.com)

## 🛠️ Tech Stack & Features
- **Frontend:** Responsive HTML5, CSS3, JavaScript.
- **Client-Centric Design:** Designed with high aesthetic standards, focusing on clean user experience (UX) and seamless mobile navigation.
- **Project Maintenance:** Multi-year lifecycle management, including code refactoring, dependency updates, and technical support.

This project demonstrates my ability to independently gather business requirements from a client, deliver a fully functional software product, and provide long-term post-deployment support.
